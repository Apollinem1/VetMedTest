## Средний приоритет

- **Table** — таблица с сортировкой, пагинацией, выбором строк
- **Pagination** — навигация по страницам (отдельный компонент)
- **Tabs** — переключение вкладок
- **Accordion** — сворачиваемые секции
- **Badge** — метки, счётчики, статусы
- **Avatar** — аватар пользователя (фото / инициалы / иконка)
- **Tooltip** — подсказки при наведении

---

## Ситуативные

- **Drawer / Sidebar** — боковая панель (для меню, фильтров)
- **Popover** — произвольный поповер с позиционированием
- **Progress / Spinner** — индикаторы загрузки (Spinner уже используется внутри Select)
- **FileUpload** — загрузка файлов с drag-and-drop
- **Breadcrumbs** — навигационные хлебные крошки
- **Stepper** — пошаговый wizard
