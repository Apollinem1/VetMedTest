# Концепт MedVet

Кратко: что за продукт, для кого, зачем и что в какую фазу выносим.

---

## Продукт в одном предложении

Платформа для владельцев животных и ветклиник: медкарта питомца (прививки, дегельминтизация, обработка от клещей, история болезней), поиск клиник на карте (2ГИС), онлайн-запись (отдельный сервис), B2B для заводчиков и ферм с аналитикой.

---

## Четыре столба ценности

От них отталкиваемся при приоритизации.

| Кому | Формулировка |
|------|--------------|
| Владелец | «Перестану терять бумажки о прививках» — всё в одном месте |
| Владелец | «Вся история питомца в одном месте» — прививки, болезни, документы |
| Клиника | «Клиенты приходят с цифровой картой» — врач видит историю, владелец выдаёт доступ при записи |
| Заводчик / B2B | «Статистика по заболеваемости» — по поголовью, тренды, прогнозы |

---

## Пользователи и роли

**Главная аудитория:** владельцы животных.

| Роль | Кто это |
|------|---------|
| Super Admin | Команда MedVet, полный доступ и модерация |
| Clinic | Юрлицо/ИП — ветклиника |
| Branch | Точка/филиал клиники |
| Clinic Admin | Администратор точки |
| Vet | Врач, привязка к одной или нескольким точкам, профиль с дипломами |
| Owner — Person | Физлицо, условно до 3–4 питомцев |
| Owner — Company | Заводчик, ферма; много питомцев, сотрудники |
| Company Employee | Сотрудник компании, права задаёт Company Admin |

Один пользователь может иметь несколько ролей (например, Vet + Clinic Admin в одиночном кабинете).

---

## Фаза 0 — первый релиз

**Цель:** база, при которой уже можно работать с животными.

**Включаем:**
- Регистрация, авторизация, логаут для всех типов пользователей
- Клиники: self-registration, модерация суперадмином (одобрить/отклонить)
- Суперадмин: модерация клиник + список пользователей, редактирование, бан, создание
- Врачи: инвайт от клиники, привязка к точке (vet_branches)
- Pending-аккаунт: клиника вводит телефон/email → создаётся pending, уходит ссылка «скачайте приложение»
- Питомцы: заведение, просмотр, редактирование
- Медбаза по животному: история болезней, дегельминтизация, обработка от клещей; сохраняем даты «следующая прививка/обработка» (отправка напоминаний — позже)

**Не в Фазе 0:**
- Биллинг и подписки
- Выдача/отзыв доступа врачу (PetAccess)
- Карта клиник и 2ГИС
- Запись на приём, уведомления (пуш/email)
- Сложная аналитика (Python-сервис)
- Экспорт данных (PDF карточки и т.п.)
- Интеграции 1С/alfaCRM

**Дальше (без жёсткой очерёдности):** биллинг, PetAccess, карта и 2ГИС, сервис записей и уведомления, аналитика, экспорт, интеграции.

## Аналитика (после Фазы 0)

| Кому | Что даём |
|------|----------|
| Владелец | Динамика веса, температуры, частота болезней по питомцу |
| Клиника | Нагрузка врачей, диагнозы, приёмы, доходы |
| B2B | Заболеваемость поголовья, прогнозы, аномалии |

---

## Поиск клиник (после Фазы 0)

- Каталог 2ГИС: список ветклиник по городу/категории из API 2ГИС.
- Поверх — слой наших клиник: у точек, подключённых к MedVet, плашка «В системе MedVet».
- Клиника при создании точки вводит название и адрес; мы сопоставляем с 2ГИС (поиск/подсказки), сохраняем `external_id_2gis` у branch.

## Регион, платформы, офлайн

- **Регион:** только РФ; смена языка/локали — позже.
- **Платформы:** веб (React) и мобилка (React Native) в приоритете; десктоп (Electron) — позже.
- **Офлайн (мобилка):** часть данных о питомце доступна без сети; локальное хранилище + синхронизация при появлении сети.

## Монетизация

**Двусторонняя:** платят и владельцы, и клиники, по разным правилам.

| Сегмент                | Модель                                                                                             |
| ---------------------- | -------------------------------------------------------------------------------------------------- |
| Владельцы              | Freemium: лимит питомцев (например, >2 — платно), снятие рекламы, доплата за уведомления о визитах |
| Клиники                | Маленький поток — не тарифицируем; крупные — подписка на уведомления и возможности сервиса записей |
| B2B (заводчики, фермы) | Всегда платно; цена по ступеням количества животных (10, 100, …)                                   |
| Реклама                | Только в мобильном приложении; не в первой фазе                                                    |

Основная выручка: подписка на уведомления (сервис записей) + B2B.
