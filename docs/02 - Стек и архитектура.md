# Стек и архитектура

Технологии, решения по API и БД, инфраструктура. Всё, что нужно для старта разработки.

---

## Стек

| Компонент            | Технология                                      |
| -------------------- | ----------------------------------------------- |
| Backend (ядро)       | Symfony (PHP 8.x)                               |
| Аналитика            | Python, FastAPI (отдельный сервис, не в Фазе 0) |
| API                  | REST, OpenAPI (Swagger), префикс `/api/v1/`     |
| БД                   | PostgreSQL                                      |
| Кэш, очереди, сессии | Redis                                           |
| Поиск                | PostgreSQL full-text; при росте — Meilisearch   |
| Файлы                | S3-совместимое хранилище (MinIO)                |
| Пуш                  | FCM, APNs (Laravel Notifications)               |
| Frontend             | React, TypeScript, Vite                         |
| Мобилка              | React Native, Expo                              |
| Офлайн (мобилка)     | WatermelonDB / SQLite + синхронизация с API     |
| Десктоп              | Electron (позже)                                |
| CI/CD                | GitLab CI                                       |

Одно API для веба и мобилки. Авторизация: email + пароль (Laravel Sanctum); веб — cookie, мобилка — Bearer. Соцсети (Google, Apple) — позже через Passport.

---

## Почему Laravel

- Роли и пермишены: `spatie/laravel-permission`.
- Доступ к сущностям: Policy + Gate (в т.ч. выдача/отзыв доступа к питомцу).
- Очереди: Laravel Queue + Horizon (Redis).
- Уведомления: мультиканал из коробки.
- Auth: Sanctum (SPA + мобилка), потом Passport при OAuth2.
- Файлы: `spatie/laravel-medialibrary` + S3/MinIO.
- Модули: `nwidart/laravel-modules` (Auth, Clinic, Pet, Medical Records, Access Control, Notifications, Integration, Billing).

## Аналитика (Python) — не в Фазе 0

Отдельный сервис: FastAPI, pandas, Prophet/scikit-learn для прогнозов. Читает PostgreSQL read-only (лучше реплика). Тяжёлые расчёты — Celery + Redis. Результаты кэшируются. Core вызывает сервис по HTTP, отдаёт ответ клиенту.

---

## Сервис онлайн-записи

Отдельная репа и деплой. Бэк записей готов; веб-морду делает команда продукта. Данные о клиниках, врачах, слотах идут из Core в сервис записей; Core — источник правды. При создании записи сервис дергает Core (webhook/API): создать PetAccess, при необходимости уведомления.

## Решения по БД

**UUID везде** как первичный ключ (безопасность, слияние при импортах).

**Soft delete** для критичных сущностей: `users`, `pets`, `visits`, `vaccinations`, `deworming_records`, `tick_treatments`, `prescriptions`, `allergies`, `chronic_conditions`, `pet_documents`, `clinics`, `branches`. Остальное — hard delete.

**Audit log:** кто, когда, что изменил в медзаписях. Пакет `owen-it/laravel-auditing`, таблица `audits`. Поля: user, event, auditable, old_values, new_values, ip_address, created_at. Применяется к visits, vaccinations, deworming_records, tick_treatments, prescriptions, pet_access, pets.

**Мультитенантность:** одна БД, изоляция по `clinic_id`/`branch_id` в строках. В Laravel — Policy и scope по tenant; при необходимости — PostgreSQL RLS.
