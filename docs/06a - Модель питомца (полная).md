# Модель данных: питомец

Поле → что значит → тип. Типы: строка, число, дата, да/нет, текст, перечисление, ссылка на сущность.

---

## Питомец

### Владелец и статус

| Поле | Что значит | Тип |
|------|------------|-----|
| Владелец (физлицо) | Владелец — пользователь-физлицо | Ссылка на пользователя |
| Владелец (компания) | Владелец — компания (B2B) | Ссылка на компанию |
| Статус | В семье / умер / передан / архив | Перечисление: активный, умер, передан, архив |

Один из владельцев обязателен при статусе «активный».

### Основные данные

| Поле | Что значит | Тип |
|------|------------|-----|
| Кличка | Имя животного | Строка |
| Вид | Собака, кошка, лошадь, КРС и т.д. | Строка или выбор из списка |
| Порода | Порода | Строка |
| Пол | Самец, самка, неизвестно | Перечисление |
| Дата рождения | Точная дата рождения | Дата |
| Год рождения | Год, если дата неизвестна | Число (год) |
| Окрас, масть | Цвет шерсти/окрас | Строка |
| Фото | Фотография питомца | Ссылка на файл |
| Приметы | Шрамы, пятна, татуировки — для опознания | Текст |
| Заметки | Общие заметки владельца | Текст |

### Идентификация (чип, документы)

| Поле | Что значит | Тип |
|------|------------|-----|
| Номер чипа | Номер микрочипа (основной/текущий) | Строка |
| Дата чипирования | Когда вживлён чип | Дата |
| Место введения чипа | Например, левая холка | Строка |
| Номер ветпаспорта | Номер ветпаспорта, если есть | Строка |
| Номер родословной | Клубная регистрация, родословная | Строка |
| Внутренний номер | Номер в хозяйстве, бирка, ошейник (B2B) | Строка |

История перечиповки — отдельная сущность «чипы питомца» (массив записей: номер, дата, место, основной, дата извлечения).

### Физическое и медицинское (сводка)

| Поле | Что значит | Тип |
|------|------------|-----|
| Кастрирован/стерилизован | Важно для назначений | Да/нет |
| Текущий вес | Вес в кг | Число |
| Когда обновлён вес | Актуальность веса | Дата и время |
| Размер | Мелкий, средний, крупный, гигант | Перечисление (опционально) |
| Группа крови | Для кошек при переливании | Строка (опционально) |

### Жизненный цикл

| Поле | Что значит | Тип |
|------|------------|-----|
| Дата смерти | Когда погиб (при статусе «умер») | Дата |
| Передан (кому) | Новый владелец в системе (при статусе «передан») | Ссылка на пользователя или компанию |
| Заметки о передаче | Кому, контакты, дата; если нового владельца нет в системе | Текст |
| Удалён | Скрыт из интерфейса, не стираем из базы | Да/нет + дата |

### B2B: группировка и происхождение

| Поле | Что значит | Тип |
|------|------------|-----|
| Группа | Гурт, секция («Корпуса 1–2», «Молодняк») | Строка |
| Загон, стойло, клетка | Где содержится | Строка |
| Мать | Мать (племучёт) | Ссылка на питомца |
| Отец | Отец (племучёт) | Ссылка на питомца |

### Страховка

| Поле | Что значит | Тип |
|------|------------|-----|
| Страховая компания | Название | Строка |
| Номер полиса | Номер полиса | Строка |
| Полис действителен до | Дата окончания | Дата |

### Предпочтения

| Поле | Что значит | Тип |
|------|------------|-----|
| Предпочитаемая клиника/точка | Для напоминаний и записи | Ссылка на точку клиники |
| Предпочитаемый врач | Для напоминаний и записи | Ссылка на пользователя-врача |

### Следующие даты (для напоминаний)

| Поле | Что значит | Тип |
|------|------------|-----|
| Следующая прививка | Ближайшая дата следующей прививки | Дата |
| Следующая дегельминтизация | Ближайшая дата | Дата |
| Следующая обработка от клещей | Ближайшая дата | Дата |

Пересчитываются из записей прививок/обработок или при открытии карточки.

### Служебное

| Поле | Что значит | Тип |
|------|------------|-----|
| Дата создания | Когда добавлен в систему | Дата и время |
| Дата изменения | Когда последний раз редактировали | Дата и время |

---

## Связанные сущности (привязаны к питомцу)

| Сущность | Что хранит |
|----------|------------|
| Доступы к питомцу | Кому выдан доступ (врач, семья) |
| Визиты | Приёмы, осмотры |
| Прививки | Записи о прививках |
| Дегельминтизация | Записи о глистогонке (название препарата в каждой записи) |
| Обработка от клещей | Записи об обработках (название средства в каждой записи) |
| Рецепты | Выписанные рецепты |
| Аллергии | Список аллергенов и реакций |
| Хронические заболевания | Диагнозы и статус |
| Документы | Файлы: ветпаспорт, родословная, анализы, сканы |

История болезни = визиты + хронические заболевания + аллергии (собирается на экране).
