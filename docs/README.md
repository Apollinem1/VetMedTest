# Документация MedVet

Документация для Obsidian: концепт, стек, схемы, модели данных.

## Как использовать в Obsidian

1. Откройте папку `docs` как хранилище (Vault) в Obsidian или добавьте её в существующее хранилище.
2. Навигация: начните с **[[00 - Index (MOC)]]** — там ссылки на все разделы.
3. Ссылки вида `[[01 - Концепт]]` ведут к другим заметкам.
4. Редактируйте заметки по мере ответов на вопросы; концепт заполняем вместе.

## Структура

- `00 - Index (MOC).md` — карта документации
- `01 - Концепт.md` — что за приложение, для кого, зачем (с вопросами)
- `02 - Стек и архитектура.md` — технологии и схемы (заготовка)
- Дальше: функциональность, модели данных, диаграммы
